# 第 1 步：服务器初始化

> 适用镜像：**Ubuntu 22.04 LTS**。若选了 CentOS/TencentOS，命令会不同，需先确认。
> 所有命令在服务器上以 `deploy` 用户执行（需管理员权限时加 `sudo`）。
> 本步是运维安全基线，与生产服务器规范一致。

---

### 1.1 先确认系统
```bash
cat /etc/os-release | head -n 2
uname -a
```
确认输出为 Ubuntu 22.04。

### 1.2 更新系统（补丁管理）
```bash
sudo apt update && sudo apt upgrade -y
```
> 运维日常：定期打补丁，避免已知漏洞被攻破。

### 1.3 创建普通用户（别一直用 root）
```bash
adduser deploy          # 按提示设密码、填信息（可一路回车）
usermod -aG sudo deploy   # 加入 sudo 组
```
> root 权限太大，规范是「普通用户 + sudo」。

### 1.4 配置 SSH 密钥登录（在本地电脑执行）
```bash
# 本地生成密钥（若已有可跳过）
ssh-keygen -t ed25519 -C "deploy@blog"

# 本地把公钥拷到服务器
ssh-copy-id deploy@服务器公网IP
```

### 1.5 加固 SSH（禁用密码登录）— 可选
登录 `deploy` 用户后：
```bash
sudo sed -i 's/^#\?PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -i 's/^#\?PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo systemctl restart sshd
```
> ⚠️ 改完先别断开当前连接，新开终端测试 `ssh deploy@IP` 能登录再继续，否则可能锁死自己。
> 本次部署中用户为方便暂未执行此步，靠 fail2ban 防爆破；环境稳定后建议补做。

### 1.6 配置防火墙 UFW
```bash
sudo apt install ufw -y
sudo ufw default deny incoming   # 默认拒绝入站
sudo ufw default allow outgoing  # 默认允许出站
sudo ufw allow 22/tcp            # SSH
sudo ufw allow 80/tcp            # HTTP
sudo ufw allow 443/tcp           # HTTPS
sudo ufw enable
sudo ufw status
```

### 1.7 安装 fail2ban（防暴力破解）
```bash
sudo apt install fail2ban -y
sudo systemctl enable --now fail2ban
```

### 1.8 基础工具 + 时区
```bash
sudo apt install -y curl wget git vim tmux htop unzip
sudo timedatectl set-timezone Asia/Shanghai
```

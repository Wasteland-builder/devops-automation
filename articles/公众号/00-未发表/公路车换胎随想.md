# 缘起

距离上一次写公众号已经过去了接近四年之久，想想也该是时候重新把它拾起来了。

其实这辆车已经在阳台躺了一年了，年中某次突发奇想骑车出去溜溜，可惜去阳台一看，前后内外胎均已破损。大抵是因为夏日温度太高没将其转移到室内，默默地罢工了吧。中间也起过修车的念头，但总是缺少点动力，在某些事情的推动下（后面有机会再单独写一篇吧，暂且卖个关子），终于算是下定决心，重拾骑行。刚好action 6也早就想买了，顺便也一起给解决了，以后骑车或者徒步啥的也都可以用得上。在迪卡侬寄修以及找朋友修之间也有过摇摆，最终还是决定自己买一下工具与配件，想着骑长途难免有啥意外，多掌握一份技能也没有什么坏处。自己动手，丰衣足食。

# 第一次修车&vlog

这既是我第一次拍vlog，也是我第一次自己修车，既然知道我的记忆不好，那还是多记录记录生活吧，以后要真能有退休的时候，也能翻看翻看一下过往，想想也是挺有意思的。

没开始前我还以为换胎是个很难的事情，但在看了下教学视频之后，感觉也就那么回事。其实就和很多事情一样，不敢于开始的话，也就慢慢错过了，所以，遇到喜欢的还是努力争取争取吧，至少不留遗憾。

至于修车过程，虽然过程有点磕磕绊绊，但总体来说还是比较顺利的。就是我那电动打气筒着实耗费了我不少时间去找，差点痛失200大洋。由此可见分门别类整理物品是一个好习惯，就算放一段时间不用也还能很快的找回来。



# 关于过往

这台 迪卡侬RC120 是我哥 一年半前送给我的，当时拿到的第二天就和他从嘉定 骑了一百多公里往返淀山湖，想想当时也真是头铁，啥装备没有都敢直接上。还好刚毕业没多久身体还能扛得住，也算是平安返回了。

后来也偶尔和同事出去骑行过几次，太仓阅兵台、滴水湖之类的，但后来离职的离职，调岗的调岗，渐渐也就我一个人骑了。不过也还好，独处惯了，一个人骑车也没有啥大不了的，自由。可惜后来因工作原因，要不就出差狠狠加班，要不就周末一直加班，人也慢慢没了朝气，怨天尤人的，对啥都提不起太大的兴趣，也就不太骑车了。

过去做好多事情都是三分钟热度，学习如此、运动也是如此。特别在学习这上面，不持续学习的话，过段时间就全都忘完了，难免会觉得当时的时间都浪费掉了，甚至还不如把那时间花去玩呢。

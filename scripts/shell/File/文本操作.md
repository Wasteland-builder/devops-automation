Linux 文本查找替换的命令很多，但真正需要熟练掌握的核心就几个：**grep、sed、awk、perl、tr、find、xargs、vim**，再配合现代工具 **rg、sd**。下面按“查找”和“替换”分类讲，最后给组合实战和速查表。

---

## 一、查找类命令

### 1. grep：最常用的文本查找

```bash
grep "pattern" file
```

常用选项：

| 选项            | 含义                         |
| --------------- | ---------------------------- |
| `-i`            | 忽略大小写                   |
| `-r`            | 递归目录                     |
| `-n`            | 显示行号                     |
| `-l`            | 只输出包含匹配的文件名       |
| `-w`            | 匹配整个单词                 |
| `-v`            | 反向匹配，输出不包含的行     |
| `-E`            | 使用扩展正则                 |
| `-F`            | 按固定字符串匹配，不解析正则 |
| `-A n`          | 显示匹配行后 n 行            |
| `-B n`          | 显示匹配行前 n 行            |
| `-C n`          | 显示匹配行前后各 n 行        |
| `--include`     | 只搜索指定文件               |
| `--exclude`     | 排除指定文件                 |
| `--exclude-dir` | 排除目录                     |

示例：

```bash
grep -rn "error" /var/log/
grep -ril "10.10.10.10" .
grep -E "error|fail|warn" app.log
grep -F "10.10.10.10" config.conf
grep -rn --include="*.conf" "Listen" /etc/
```

注意：`grep` 默认使用基本正则，`.`、`*`、`[`、`]`、`^`、`$`、`\` 等是特殊字符。查找 IP 时要写成：

```bash
grep '10\.10\.10\.10' file
```

---

### 2. rg：ripgrep，更快的现代查找工具

```bash
rg "pattern"
```

特点：

- 默认递归搜索
- 默认忽略 `.gitignore`、`.git`、隐藏文件
- 速度快
- 支持正则和 Unicode

常用：

```bash
rg -n "error"
rg -i "timeout"
rg -l "10.10.10.10"
rg -F "10.10.10.10"
rg --hidden "secret"
```

如果系统没装，可以：

```bash
sudo apt install ripgrep
# 或
sudo yum install ripgrep
```

---

### 3. find：按文件名或属性查找

`find` 本身不查找文件内容，但常和 `grep`、`sed` 组合。

```bash
find . -name "*.conf"
find . -type f -name "*.log"
find . -type f -mtime -7
find . -type f -size +100M
```

查找内容：

```bash
find . -type f -name "*.conf" -exec grep -n "10.10.10.10" {} +
```

---

### 4. locate：快速定位文件

```bash
locate nginx.conf
```

需要先更新数据库：

```bash
sudo updatedb
```

## 二、替换类命令

### 1. sed：最经典的流式替换

基本替换：

```bash
sed 's/old/new/g' file
```

含义：

- `s`：substitute，替换
- `/old/new/`：旧内容替换为新内容
- `g`：一行中所有匹配都替换，不加只替换每行第一个

常用选项：

| 选项     | 含义                         |
| -------- | ---------------------------- |
| `-i`     | 直接修改原文件               |
| `-i.bak` | 修改原文件并生成 `.bak` 备份 |
| `-n`     | 不自动输出，常和 `p` 配合    |
| `-E`     | 使用扩展正则                 |

示例：

```bash
# 只预览，不修改
sed 's/10\.10\.10\.10/11.11.11.11/g' config.conf

# 原地修改，生成 config.conf.bak
sed -i.bak 's/10\.10\.10\.10/11.11.11.11/g' config.conf

# 只替换第 10 到 20 行
sed -i '10,20s/old/new/g' file

# 匹配某行再替换
sed -i '/server_name/s/old/new/g' file

# 使用扩展正则
sed -E -i 's/(foo|bar)/baz/g' file
```

正则注意：

- 旧内容中的 `.` 要写成 `\.`
- `*`、`[`、`]`、`^`、`$`、`\` 等也要按需转义
- 替换内容中的 `&` 表示整个匹配，`\1` 表示第一个捕获组

示例：

```bash
sed -E 's/([0-9]+)\.([0-9]+)/\2.\1/' file
```

---

### 2. awk：按字段处理，适合结构化文本

替换函数 `gsub`：

```bash
awk '{gsub(/old/, "new"); print}' file
```

原地修改需要借助临时文件：

```bash
awk '{gsub(/old/, "new"); print}' file > tmp && mv tmp file
```

按列替换：

```bash
awk -F: '{gsub(/old/, "new", $3); print}' file
```

示例：

```bash
# 把第 2 列中的 10.10.10.10 换成 11.11.11.11
awk -F, 'BEGIN{OFS=","} {gsub(/10\.10\.10\.10/, "11.11.11.11", $2); print}' file
```

适合：

- CSV、TSV、冒号分隔文件
- 只替换某一列
- 按条件替换

---

### 3. perl：正则能力最强，原地替换方便

```bash
perl -pi -e 's/old/new/g' file
```

常用：

```bash
# 原地替换，生成 .bak 备份
perl -pi.bak -e 's/10\.10\.10\.10/11.11.11.11/g' file

# 只替换包含某字符串的行
perl -pi -e 's/old/new/g if /pattern/' file

# 使用环视，避免误伤
perl -pi -e 's/(?<!\d)10\.10\.10\.10(?!\d)/11.11.11.11/g' file
```

优点：

- 支持高级正则：环视、非贪婪、命名捕获等
- `-pi` 原地替换非常方便
- 跨平台比 `sed -i` 更一致

---

### 4. tr：字符级替换、删除、压缩

`tr` 只能做单字符映射，不支持字符串替换。

```bash
# 小写转大写
tr 'a-z' 'A-Z' < file

# 删除 Windows 换行符 \r
tr -d '\r' < file > newfile

# 压缩连续空格
tr -s ' ' < file

# 替换字符
tr 'abc' 'xyz' < file
```

适合：

- 大小写转换
- 删除特定字符
- 压缩重复字符
- 处理换行符

---

### 5. vim：交互式替换

在 vim 中：

```vim
:%s/old/new/g
```

含义：

- `%`：整个文件
- `s`：替换
- `g`：每行所有匹配
- `c`：替换前确认

常用：

```vim
:%s/old/new/gc
:10,20s/old/new/g
:.,$s/old/new/g
```

适合：

- 需要人工确认的替换
- 复杂文件局部替换
- 交互式编辑

---

### 6. sd：更简单的现代替换工具

```bash
sd 'old' 'new' file
```

特点：

- 语法比 sed 简单
- 默认使用正则
- 支持原地替换

示例：

```bash
sd '10\.10\.10\.10' '11.11.11.11' config.conf
```

需要安装：

```bash
cargo install sd
# 或
sudo apt install sd
```

## 三、组合实战：批量查找替换

### 1. 先查找哪些文件包含旧内容

```bash
grep -rIl '10\.10\.10\.10' .
```

说明：

- `-r` 递归
- `-I` 忽略二进制
- `-l` 只输出文件名

### 2. 批量替换，带备份

Linux：

```bash
grep -rIlZ --exclude='*.bak' --exclude-dir='.git' '10\.10\.10\.10' . \
  | xargs -0 -r sed -i.bak 's/10\.10\.10\.10/11.11.11.11/g'
```

macOS：

```bash
grep -rIlZ '10\.10\.10\.10' . \
  | xargs -0 sed -i '.bak' 's/10\.10\.10\.10/11.11.11.11/g'
```

### 3. 只替换特定后缀文件

```bash
find . -type f \( -name '*.conf' -o -name '*.yaml' -o -name '*.yml' \) -print0 \
  | xargs -0 grep -IlZ '10\.10\.10\.10' \
  | xargs -0 -r sed -i.bak 's/10\.10\.10\.10/11.11.11.11/g'
```

### 4. 使用 perl 批量替换

```bash
grep -rIlZ '10\.10\.10\.10' . \
  | xargs -0 -r perl -pi.bak -e 's/10\.10\.10\.10/11.11.11.11/g'
```

## 四、常用命令速查表

| 命令    | 主要用途      | 常用示例                                       |
| ------- | ------------- | ---------------------------------------------- |
| `grep`  | 查找文本      | `grep -rn "error" .`                           |
| `rg`    | 快速查找      | `rg -n "error"`                                |
| `find`  | 查找文件      | `find . -name "*.conf"`                        |
| `sed`   | 流式替换      | `sed -i.bak 's/old/new/g' file`                |
| `awk`   | 按列替换      | `awk '{gsub(/old/,"new");print}' file`         |
| `perl`  | 高级正则替换  | `perl -pi.bak -e 's/old/new/g' file`           |
| `tr`    | 字符替换/删除 | `tr 'a-z' 'A-Z' < file`                        |
| `vim`   | 交互式替换    | `:%s/old/new/gc`                               |
| `sd`    | 简单替换      | `sd 'old' 'new' file`                          |
| `xargs` | 组合批量处理  | `grep -rl old . \| xargs sed -i 's/old/new/g'` |

---

## 五、核心原则

1. **查找优先用 `grep -rIl`**，先确认范围。
2. **替换优先用 `sed -i.bak`**，先备份再改。
3. **旧内容中的正则特殊字符要转义**，尤其是 `.`。
4. **文件名可能带空格**，用 `-print0` 和 `xargs -0`。
5. **macOS 和 Linux 的 `sed -i` 不同**，注意区分。
6. **复杂正则用 `perl`**，简单替换用 `sed`。
7. **结构化文本用 `awk`**，字符级替换用 `tr`。

掌握这几组，基本就能覆盖 Linux 下 90% 的文本查找替换场景。

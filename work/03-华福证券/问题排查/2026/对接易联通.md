# 一、逻辑梳理

## 获取清算文件(搭建sftp)

#### 第一步：创建用户和组

```bash
# 1. 创建 sftp 用户组（如果 hssftp 组已存在可跳过）
groupadd hssftp 

# 2. 创建用户，指定组、不创建家目录、禁止 shell 登录
useradd -g hssftp -s /sbin/nologin -M hssftp

# 3. 设置密码
passwd hssftp
```

#### 第二步：创建目录并设置严格权限

```bash
# 1. 创建 SFTP 根目录（Chroot 目录）
mkdir -p /data/hssftp

# 2. 关键：Chroot 目录的所有者必须是 root，权限最大为 755
chown root:root /data/hssftp
chmod 755 /data/hssftp

# 3. 在根目录下创建一个子目录（例如 upload），这个目录才归用户所有
mkdir -p /data/hssftp/download
chown hssftp:hssftp /data/hssftp/download
chmod 755 /data/hssftp/download
```

*注：用户登录 SFTP 后，看到的根目录是 `/data/hssftp`，但他没有写入权限；他只能把文件上传到 `/data/hssftp/upload` 目录下。*

#### 第三步：修改 SSH 配置文件

```bash
vi /etc/ssh/sshd_config
```

找到 `Subsystem sftp` 这一行，注释掉原来的，添加以下配置：

```text
# Subsystem sftp /usr/libexec/openssh/sftp-server
Subsystem sftp internal-sftp

Match User hssftp
    ChrootDirectory /data/hssftp
    ForceCommand internal-sftp
    AllowTcpForwarding no
    X11Forwarding no
```

#### 第四步：检查配置并重启服务

```bash
# 检查配置文件是否有语法错误（无输出代表正确）
sshd -t 

# 重启 sshd 服务使配置生效
systemctl restart sshd
```

#### 第五步：测试登录

```bash
sftp hssftp@你的服务器IP
```

按照以上步骤操作，才能确保你的 SFTP 服务既能正常连接，又能保证服务器系统级别的安全。



## sftp挂载windows机器（Linux 挂载 Windows 目录）

### Linux 需要访问 Windows 上的文件

方法：Windows 开启共享，Linux 挂载

**Windows 端（提供共享）：**

1. 右键文件夹 → **属性** → **共享** → **高级共享**
2. 勾选"共享此文件夹"，设置权限
3. 确保 Windows 防火墙允许 SMB（端口 445）

**Linux 端（挂载）：**

```bash
# 安装 cifs-utils
sudo apt install cifs-utils
yum install -y cifs-utils

# 创建挂载点
sudo mkdir -p /mnt/windows_share

# 挂载（需要 Windows 用户名密码）
# 先查该用户的 UID：id appuser，然后对应设置
sudo mount -t cifs //10.35.250.14/jglc /data/hssftp/download -o "username=itadm,password=XMZ&cs500028,uid=1000,gid=1000"

# 或加到 /etc/fstab 开机自动挂载
//windows-ip/sharename /mnt/windows_share cifs credentials=/root/.smbcredentials,uid=1000,gid=1000 0 0
```
